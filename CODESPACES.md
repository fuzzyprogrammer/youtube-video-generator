# GitHub Codespaces Setup Guide 🌐

## What is GitHub Codespaces?

GitHub Codespaces is a **complete development environment in the cloud** - no installation needed! You get:
- ✅ Full backend running
- ✅ Control panel UI at http://localhost:3000
- ✅ All dependencies pre-installed
- ✅ Works in your browser
- ✅ Fully powered and ready to go

## 🚀 Quick Start (3 Steps)

### Step 1: Open Codespaces
Go to your repository and click:
```
Code → Codespaces → Create codespace on main
```

Or use this URL:
```
https://github.com/fuzzyprogrammer/youtube-video-generator/codespaces/new
```

### Step 2: Wait for Setup (1-2 minutes)
- Environment builds automatically
- Dependencies install automatically
- You'll see status updates in the terminal

### Step 3: Start the App
Once the terminal shows "✅ Codespaces environment setup complete!", run:

```bash
npm start
```

Then open the "Ports" tab and click the link for port 3000!

## 📊 How to Access Your App

## ⚙️ Codespaces Features

### 🔌 Auto Port Forwarding
Ports 3000 and 8000 are automatically accessible:
- **3000** - Control Panel UI
- **8000** - API Server (optional)

### 💾 Persistent Storage
Your generated videos and data persist across sessions!

### 🔄 Resume Sessions
Stop a session anytime. Resume later - everything is saved:
```
Your Codespaces → Select existing → Resume
```

### 🚀 Performance
- High-powered VM
- Fast deployment
- Instant file access
- Real-time updates

## 🐛 Troubleshooting

### Port Not Accessible
```
Reload page or click Port 3000 again
```

### Server won't start
```bash
# In terminal:
npm install
npm start
```

### Need to rebuild environment
```
Stop Codespace → Create new one
```

### Lost connection
```
Refresh browser and reconnect
```

## 📊 Managing Codespaces

### View All Your Codespaces
```
github.com/codespaces
```

### Stop a Codespace
- Right-click on codespace
- Select "Stop codespace"
- Resumes later with all data intact

### Delete a Codespace
- Right-click on codespace
- Select "Delete"
- Frees up storage quota

## 🎯 Free Tier Limits

GitHub Codespaces includes:
- **2-core** machine (adequate)
- **120** hours/month free
- **15 GB** storage per codespace

For more power:
- Upgrade to 4-core or 8-core machine
- Charge applies for usage over free tier
